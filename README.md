# Trepang2 - Skip Intro

A [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) mod for **Trepang2** that skips the intro screens and boots straight to the main menu.

## Requirements
- Trepang2

UE4SS v3.0.1 is included in the download, so you don't need to install it separately.

## Installation

Download the latest from [Releases](https://github.com/evilbananas/Trepang2-SkipIntro/releases) and extract it into the top-level `Trepang2` game folder, the one containing `CPPFPS.exe`.

You should end up with:
```
Trepang2\CPPFPS\Binaries\Win64\
├── Mods\SkipPressAnyKey\
├── dwmapi.dll
├── UE4SS.dll
├── UE4SS-settings.ini
└── UE4SS_LICENSE.txt
```

> If already using UE4SS, extract only the `Mods\SkipPressAnyKey` folder into your existing UE4SS `Mods` folder.

## Uninstall
- **Remove the mod:** delete the `CPPFPS\Binaries\Win64\Mods\SkipPressAnyKey` folder.
- **Remove UE4SS:** delete `dwmapi.dll`, `UE4SS.dll`, `UE4SS-settings.ini`, `UE4SS_LICENSE.txt` and the `Mods` folder from `CPPFPS\Binaries\Win64\`. Also delete `UE4SS.log` and any `.cache` files if they're there.
